# GPT-Image2-Studio v0.3.000

`v0.3.000` 是**本 fork 的版本线起点**：分支 `legacy-v0.2.116` 从上游 `aEboli/GPT-Image2-Studio` 的 `v0.2.116`（commit `7b7f8f6`）重建，随后逐张移植经研判确有必要的 fork 能力。版本号从 `0.2.116` 跳到 `0.3.000`，是为了让 fork 独占 `0.3.x` 线：上游在 `0.2.x` 上继续前进时不会与本仓库撞号，而 `0.3.000` 在 semver 上严格新于 `0.2.116`。

## 更新内容

- **基线重建**：以 `v0.2.116` 为底重建，剥除 Electron 桌面线（`desktop/`、`build/desktop/`、桌面构建依赖），锁文件从 504 个包降到 264 个。
- **安全文档**：采纳上游 `SECURITY.md` 并订正其中照抄的 Electron 桌面段——本 fork 不提供桌面客户端。
- **JSON 加固**：把 quarantine 能力增量移植进上游 `atomic-json-file`，损坏状态文件重命名为固定 `.corrupt` 后缀而不是删除或报错。
- **下载目录**：配置面板新增「图片保存目录」，独立路由 `POST /api/download-directory/save` 只存该字段，避免整段配置写回时静默重置 `baseUrl`。
- **站点品牌**：自定义站点名称与标签页图标，整组接管上游的多入口 `<link>` 图标。
- **图库窗口**：窗口模型重做为两级正交——日期页决定「看哪些天」，页内窗口决定「当前页画多少张」；摘要改报「已画 / 本页总数」。
- **粘贴加固**：保留上游 3 个粘贴 handler 并各自加快照硬化，另注册后置全局兜底，覆盖 reference-analysis / image-decomposition / portrait 三个上游没有的视图。
- **分享码与套图**：`PROMPT-KIT.V1.` 分享码（含 `params` 与 `analyzeTitle`）、提示词套组三件套、图库「下载所选」。

## 版本规则

- 小版本升级：次版本 +1，更新位归零。
- 版本格式为 `major.minor.patch`，patch 固定三位数字；上级版本变化时，下级版本归零。
- tag 用 `v0.3.000`；同一提交另挂 `fork-v0.3.000` 别名，供人一眼区分上游原版。

## 升级说明

- 既有配置、生成记录和图片资产不需要迁移。
- 商品图采集扩展使用独立版本线，本次主应用更新不会修改扩展版本。

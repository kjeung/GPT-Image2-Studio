## REMOVED Requirements

### Requirement: 图片详情显示请求发起 IP

请求发起 IP 不再在图片详情或参数文本中展示。图片详情参数页 MUST NOT 显示“请求发起IP”，参数列表 SHALL 只包含生成时的参数与保存的文件等既有条目。新生成图片记录仍可保存服务端在生成请求期间通过上游 HTTP transport 查询到的公网出口 IP，该值 MUST NOT 从浏览器访问地址推导；已有历史记录 SHALL NOT 被当前访问者地址补写或迁移。

#### Scenario: 查看新生成图片的参数

- **WHEN** 用户打开保存了服务端出口 IP 的生成图片并选择“参数”
- **THEN** 参数列表不包含请求发起 IP 条目
- **AND** 其余参数列表正常显示

#### Scenario: 查看旧图片的参数

- **WHEN** 用户打开没有请求发起 IP 字段的历史图片并选择“参数”
- **THEN** 参数列表不包含请求发起 IP 条目
- **AND** 系统不使用当前浏览器连接地址补写该字段

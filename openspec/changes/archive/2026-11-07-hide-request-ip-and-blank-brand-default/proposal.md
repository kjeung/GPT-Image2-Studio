## 原因

两个面向用户的偏好被反复提出，需要与实现对齐：

- 页面多处（配置面板「当前调用」摘要、图片详情参数列表）展示了「请求发起 IP」，用户要求不再显示。
- 品牌 LOGO 配置的「品牌名称」预填 `aEboli`，顶部标题也静默写死该名称，用户要求默认留空、未填时标题行不占位；用户填了品牌名才显示。

## 改动范围

- 界面层移除请求发起 IP 的两处展示：配置面板当前调用摘要与图片详情 / 参数文本。后端仍记录 `requestIp`，此变更不改变存储与接口字段。
- 「当前参数摘要显示生图请求 URL」需求不再引用 IP 行位置，改为相对模型信息出现。
- `DEFAULT_SITE_BRAND.name` 由 `"aEboli"` 改为空字符串；品牌弹窗预览的静态文案同步清零；页面标题继续保留 `"IS"` 直至用户命名。
- 顶部标题行由品牌控制器接管：名称为空时整行隐藏（`hidden`），只保留图形标识与副标题；用户填入名称后显示。

## 不在本次范围

- 存储与 API 返回中的 `requestIp` 字段本身（保持不变）。
- 品牌副标题默认值 `AI 图像生成工作流`（与顶部副标题一致，保持原状）。
- 图标 / favicon 接管逻辑。

## 验收

- 图片详情参数与当前调用摘要不再出现「请求发起 IP」；后端记录仍有该字段。
- 品牌名称输入框默认空值，仅显示占位提示；顶部无 `aEboli` 残留；无品牌名时标题行不占位。
- `openspec validate --all --strict` 与全部发布检查通过。
